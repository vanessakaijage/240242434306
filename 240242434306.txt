I learned that data mining is the process of discovering useful patterns and knowledge from large datasets, using ideas from machine learning, statistics, AI, and database systems. It is the core step of the Knowledge Discovery in Databases (KDD) process, an iterative sequence of data cleaning, data integration, data selection, data transformation, data mining, pattern evaluation, and knowledge presentation through visualization. Before mining, data must be understood and prepared. Data objects are described by attributes, which can be nominal (unordered categories), binary (two values), ordinal (ordered values), or numeric (interval-scaled or ratio-scaled), and either discrete or continuous. To detect noise and outliers, we examine the center of the data (mean, median, mode), its spread, and the relationships between attributes.
The main focus was measuring similarity and dissimilarity between objects, which is important for clustering, outlier detection, and nearest-neighbor classification. Similarity ranges from 0 (completely different) to 1 (identical), and dissimilarity = 1 - similarity. For nominal data, dissimilarity is d(i,j) = (p - m) / p, where p is the number of attributes and m is the number of matches. For binary data we use a contingency table (q = both 1, r = 1 and 0, s = 0 and 1, t = both 0) and the Jaccard coefficient, with dissimilarity = (r + s) / (q + r + s), ignoring “both zero” matches. For numeric data we use Euclidean, Manhattan, Minkowski, Supremum, and weighted Euclidean distances.
